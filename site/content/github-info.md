## Recent GitHub Changelog highlights

- **Copilot code review can now approve pull requests** — Copilot code review adds
  approval assessments to its overview comment and, once an admin turns the
  feature on at the enterprise, organization, or repository level, Copilot can
  sign off on a pull request itself. Off by default, in public preview for
  Copilot Pro, Pro+, Max, Business, and Enterprise plans. (Source:
  github.blog/changelog)
- **GitHub CLI: media in issues, pull requests, and comments** — `gh` now
  supports a repeatable `--attach` flag that uploads a local image or video and
  references it inline in an issue, pull request, or comment body, making it
  easier to show a UI bug or rendered result instead of describing it in text.
  Generally available to everyone; requires `gh` v2.99.0 or later. (Source:
  github.blog/changelog)
- **GitHub Copilot in VS Code, August 2026 releases** — a recap of the latest
  Copilot updates shipped to VS Code that month, useful for developers who want
  a quick way to catch up on IDE-side Copilot changes without reading every
  individual release note. (Source: github.blog/changelog)

Check github.blog/changelog regularly, since GitHub ships product updates
almost daily and this list will age quickly.
