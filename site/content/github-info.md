## Recent updates worth watching (GitHub Changelog)

- **Copilot Code Review can now approve pull requests** — Copilot's automated code review can mark a PR as approved when it finds no blocking issues, speeding up low-risk review cycles. (source: github.blog/changelog, September 1, 2026)
- **GitHub CLI supports media in issues, pull requests, and comments** — `gh` can now attach images and other media directly when creating or updating issues, PRs, and comments, no browser upload step required. (source: github.blog/changelog, September 1, 2026)
- **Content exclusions are generally available in the Copilot app and CLI** — Teams can mark files and paths as off-limits so Copilot skips them across the app and CLI, not just the IDE. (source: github.blog/changelog, September 2, 2026)
- **Individual user budgets can now have an expiration date** — Admins can set a budget that automatically expires, useful for time-boxed Copilot or Actions spending limits. (source: github.blog/changelog, September 1, 2026)
- **Multiple trusted publishing configurations for npm** — npm packages can now be configured with more than one trusted publisher, making it easier to manage CI/CD publishing across providers. (source: github.blog/changelog, September 3, 2026)

## What's new in GitHub Copilot models

- GPT-6 Astra and Gemini 3 8 Flash are now generally available as model choices in GitHub Copilot, alongside Claude Fable 5.1. (source: github.blog/changelog, September 2026)
- Some older Copilot models are being deprecated soon — check the changelog before pinning a model in scripts or settings. (source: github.blog/changelog, September 3, 2026)
