## Recent GitHub Changelog highlights (September 2026)

- **Copilot code review can now approve pull requests** — Copilot's automated
  code review can mark a pull request as approved, not just leave comments,
  streamlining review workflows. (Source: GitHub Changelog, 2026-09-01)
- **GitHub CLI media in issues, pull requests, and comments** — the `gh` CLI
  can now attach images and other media directly when creating or updating
  issues, pull requests, and comments. (Source: GitHub Changelog, 2026-09-01)
- **Content exclusions generally available in Copilot app and CLI** — teams
  can exclude specific files or paths from Copilot's context across the
  Copilot app and CLI, giving finer control over what Copilot can read.
  (Source: GitHub Changelog, 2026-09-02)
- **Rule insights dashboard generally available** — organizations get a
  dashboard showing how repository rulesets are enforced across repos, making
  it easier to audit branch and push protections at scale. (Source: GitHub
  Changelog, 2026-08-25)
- **Agent plugins 1.0 in VS Code, Copilot CLI, and the Copilot app** — a
  shared plugin format lets developers extend Copilot consistently across
  editors and the CLI. (Source: GitHub Changelog, 2026-08-12)

Practical takeaway for developers: Copilot code review keeps closing the gap
with a full reviewer, agent plugins make Copilot extensible the same way
across tools, and new governance features (rule insights, content exclusions)
give teams more visibility and control as they adopt Copilot and Actions at
scale.
