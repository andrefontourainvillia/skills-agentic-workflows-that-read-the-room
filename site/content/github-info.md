## Current homepage themes

- GitHub collaboration basics: repositories, branches, pull requests, and merges.
- GitHub Copilot as an AI coding assistant across the IDE, CLI, and GitHub.
- GitHub Actions as the automation layer behind repository workflows.
- Recent GitHub Blog and Changelog stories worth watching.

## Recent GitHub Blog highlights

- **Review agent work without leaving the Copilot app.** The Copilot app now has built-in diff, terminal, and browser panels, so you can review changes, run commands, and preview a web app side by side. (Source: GitHub Blog)
- **Run several agents at once.** The Copilot app for Beginners series shows how to kick off and track multiple Copilot coding agent sessions in parallel instead of waiting on one at a time. (Source: GitHub Blog)
- **Automate Dependabot pull request triage.** A walkthrough on using Copilot to review, label, and merge routine Dependabot updates so they don't pile up in your queue. (Source: GitHub Blog)

## Recent GitHub Changelog highlights

- **Refreshed repository pull requests page (public preview).** A new PR list view adds content-assist filtering, `AND`/`OR` advanced search, a collapsible sidebar for quick filters like "Authored by me," and a compact presentation mode. (Source: GitHub Changelog)
- **AI Scan for pull request APIs (public preview).** Teams can now trigger AI-powered security scans on pull requests directly through the API, making it easier to wire security checks into custom automation. (Source: GitHub Changelog)
- **Block pull requests with exposed secrets from merging.** GitHub Advanced Security can now stop a PR from merging if it contains a detected secret, closing a common gap between scanning and enforcement. (Source: GitHub Changelog)
- **Control GitHub Actions cache access with `cache-mode`.** A new setting lets you scope which workflows and branches can read or write the Actions cache, reducing the risk of cache poisoning. (Source: GitHub Changelog)
