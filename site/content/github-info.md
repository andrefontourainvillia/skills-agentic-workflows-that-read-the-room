## Recent GitHub updates worth watching

_Source: [github.blog/changelog](https://github.blog/changelog/)_

- **Copilot code review can approve pull requests** — Copilot now flags when a
  pull request is ready to approve, and admins can authorize it to sign off on
  the approval itself (opt-in, off by default). ([changelog](https://github.blog/changelog/2026-09-01-copilot-code-review-can-now-approve-pull-requests))
- **GitHub CLI can attach media to issues and PRs** — `gh` now supports a
  repeatable `--attach` flag that uploads a local image or video and embeds it
  inline in an issue, pull request, or comment body. ([changelog](https://github.blog/changelog/2026-09-01-github-cli-media-in-issues-pull-requests-and-comments))
- **Block pull requests with exposed secrets from merging** — A new repository
  ruleset rule, "require secret scanning alerts are resolved," blocks merges
  until secret scanning alerts are cleared; available in public preview for
  GitHub Secret Protection and Advanced Security customers. ([changelog](https://github.blog/changelog/2026-09-09-block-pull-requests-with-exposed-secrets-from-merging))
- **Agentic autofix for code quality findings** — Select up to 25 standard code
  quality findings on a page and have Copilot's agentic autofix generate fixes
  to help burn down your backlog. ([changelog](https://github.blog/changelog/2026-09-09-remediate-code-quality-findings-with-agentic-autofix))
- **GitHub Actions early September 2026 updates** — Includes a new REST API for
  runner version deprecations plus other workflow visibility and control
  improvements. ([changelog](https://github.blog/changelog/2026-09-03-github-actions-early-september-2026-updates))
