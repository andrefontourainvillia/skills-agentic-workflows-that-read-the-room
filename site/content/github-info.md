## Latest GitHub Updates

### Copilot code review: an improved review experience

Copilot code review now shows a clearer overview of how a review changes over time, grouping findings into Open, Resolved since last review, and Previously missed sections. Comments also get concise titles and smarter auto-resolution, and Copilot can generate commit messages when you accept suggestions in a batch. These updates are now generally available.

*Source: GitHub Changelog, September 18, 2026*

### Workflow execution protections in GitHub Actions are now generally available

Execution protections for GitHub Actions, previously in public preview, are now generally available for GitHub Enterprise, organizations, and repositories. Admins can define an allowlist that controls who can trigger workflow runs, helping reduce the risk of unauthorized or unexpected automation.

*Source: GitHub Changelog, September 17, 2026*

### Ubuntu 26 runner image is now generally available

The Ubuntu 26.04 runner image for GitHub Actions is out of public preview and fully supported for production workflows on both x64 and arm64. Teams still on Ubuntu 22.04 or 24.04 should review GitHub's migration guidance ahead of older image deprecations.

*Source: GitHub Changelog, September 17, 2026*

### Upcoming deprecation of selected Copilot models in mid-October

GitHub will deprecate a set of Copilot models across Copilot Chat, inline edits, ask and agent modes, and code completions on October 19, 2026. Teams relying on those models should check the changelog post and switch to a supported model before the deprecation date.

*Source: GitHub Changelog, September 18, 2026*
