- Recent GitHub Blog and Changelog stories worth watching.

## Recent Changelog highlights (github.blog/changelog)

- **Copilot code review can now approve pull requests** — Copilot flags when a
  pull request is ready to approve, and admins can authorize it to sign off on
  the approval itself (off by default).
- **Refreshed repository pull requests page (public preview)** — a new
  repository-level pull request listing with better filtering and a compact
  presentation mode, rolling out to all GitHub users.
- **GitHub CLI media attachments** — `gh` now supports a repeatable `--attach`
  flag to upload a local image or video and reference it inline in an issue,
  pull request, or comment body.
- **Configurable cost and quality in Copilot auto model selection** — auto
  model selection now offers efficiency, balance, and intelligence tiers so
  teams can tune cost, quality, and response time.
- **Block pull requests with exposed secrets from merging** — repository
  rulesets can now stop a pull request from merging if it introduces an
  exposed secret.
