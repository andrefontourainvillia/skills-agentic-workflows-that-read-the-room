## Recent GitHub Blog and Changelog stories worth watching

- Repositories now show a refreshed **Pull requests** page, in public preview, making it easier to scan and triage open PRs at a glance. (Source: GitHub Changelog)
- **AI scan for pull request APIs** is in public preview, letting teams run automated AI-driven checks against PRs via the API. (Source: GitHub Changelog)
- GitHub Actions gained a new **cache-mode** control for GitHub Actions cache access, giving workflows finer-grained control over read/write cache permissions. (Source: GitHub Changelog)
- Organizations can now **block pull requests with exposed secrets from merging**, adding an extra guardrail before secrets reach the default branch. (Source: GitHub Changelog)
- Copilot Code Review added **auto-resolution and analysis updates**, helping reviewers close out addressed feedback faster. (Source: GitHub Changelog)
- The GitHub Blog explored **how canvases make agentic workflows visible, steerable, and cost efficient** — a good read for anyone building with Copilot's agent features. (Source: GitHub Blog)
- A new blog post breaks down **how to bring your software delivery workflow into GitHub with agent apps**, useful context for teams adopting Copilot agents end to end. (Source: GitHub Blog)
