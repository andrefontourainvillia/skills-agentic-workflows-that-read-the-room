## Recent GitHub Blog and Changelog stories

- **GitHub Enterprise Server 3.22 is now generally available** — the latest GHES release adds new platform capabilities, including the ability for administrators to configure Copilot CLI for their organization. ([GitHub Changelog](https://github.blog/changelog/2026-09-08-github-enterprise-server-3-22-is-now-generally-available/))
- **Automatic Dependabot access to GitHub-hosted registries** — Dependabot can now read from private GitHub Packages registries without a personal access token, as long as the package has granted repository access through "Manage Actions access." ([GitHub Changelog](https://github.blog/changelog/2026-09-08-automatic-dependabot-access-to-github-hosted-registries/))
- **New API endpoint provides privacy-safe star history data** — a new star history REST API endpoint lets you track repository star growth over time without exposing individual stargazer identities. ([GitHub Changelog](https://github.blog/changelog/2026-09-04-new-api-endpoint-provides-privacy-safe-star-history-data/))
- **GitHub Actions: Early September 2026 updates** — three updates give clearer visibility and finer-grained control over workflows, including a new REST API for runner version deprecations. ([GitHub Changelog](https://github.blog/changelog/2026-09-03-github-actions-early-september-2026-updates/))
- **Multiple trusted publishing configurations for npm** — npm publishing now supports multiple trusted publishing configurations per package, making it easier to publish safely from more workflows. ([GitHub Changelog](https://github.blog/changelog/2026-09-03-multiple-trusted-publishing-configurations-for-npm/))
- **How we make AI coding more cost efficient without sacrificing task quality** — a look at why shorter Copilot outputs can sometimes cost more, and how GitHub reduces wasted work across a coding task. ([GitHub Blog](https://github.blog/ai-and-ml/github-copilot/how-we-make-ai-coding-more-cost-efficient-without-sacrificing-task-quality/))
- **GitHub Copilot app for Beginners: Run several agents at once** — a beginner-friendly walkthrough of running parallel Copilot agent sessions from the Copilot app. ([GitHub Blog](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-run-several-agents-at-once/))
