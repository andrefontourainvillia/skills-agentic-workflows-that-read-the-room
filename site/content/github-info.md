## Recent stories worth watching

- **Copilot code review: an improved review experience** — Copilot code review now shows clearer review progress over time, more intelligently auto-resolves its own suggestions, and generates commit messages when you accept suggestions in a batch. (Source: [github.blog/changelog](https://github.blog/changelog/2026-09-18-copilot-code-review-an-improved-review-experience))
- **Workflow execution protections in GitHub Actions are generally available** — Enterprises, organizations, and repositories can now define allowlists that control which actors can trigger a workflow and which events can start it, including scoping rules to specific workflow files. (Source: [github.blog/changelog](https://github.blog/changelog/2026-09-17-workflow-execution-protections-in-github-actions-generally-available))
- **Upcoming deprecation of selected GitHub Copilot models** — GitHub is deprecating several Copilot models across Chat, inline edits, ask/agent modes, and code completions on October 19, 2026; teams should check their model selections ahead of the cutover. (Source: [github.blog/changelog](https://github.blog/changelog/2026-09-18-upcoming-deprecation-of-selected-github-copilot-models-in-mid-october))
- **Stage-only npm tokens for safer automation** — Granular npm access tokens now support a "Read and write (stage only)" scope, letting automated publishing workflows stage package versions for review without granting full publish rights. (Source: [github.blog/changelog](https://github.blog/changelog/2026-09-18-stage-only-npm-tokens-for-safer-automation))
