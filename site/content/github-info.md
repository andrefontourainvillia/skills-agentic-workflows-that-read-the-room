## Recent updates worth watching

- **More ways to request and configure Copilot code reviews** — Copilot code review now supports personal configuration options across more Copilot plans, plus an enterprise-level default setting, so teams can turn on automatic reviews without per-repo setup. (github.blog/changelog, Sep 23, 2026)
- **Agentic autofix now uses Copilot Memory** — When agentic autofix resolves a security alert for customers who've enabled Copilot Memory, it checks existing memories for relevant context first, making fixes more consistent with how a team already works. (github.blog/changelog, Sep 25, 2026)
- **Private saved views for repository issues, generally available** — Repository issues pages now support private saved views, so developers can save personalized filters instead of re-entering them every time; the "Relates to" issue relationship also shipped alongside it. (github.blog/changelog, Sep 25, 2026)
- **New models in GitHub Copilot** — Claude Opus 5.5 and OpenAI's GPT-6 Sol and GPT-6 Luna are now available as model choices in Copilot, giving developers more options for agentic coding and long-running tasks. (github.blog/changelog, Sep 22, 2026)
- **Weekly Copilot release recap** — GitHub's weekly Copilot changelog roundup covers new models, local sandboxing in the Copilot app, and updates to Copilot in Slack, Microsoft Teams, JetBrains, and VS Code — a good one-stop link for anyone tracking Copilot's pace of change. (github.blog/changelog, Sep 25, 2026)
- **Decoding the new AI lingo** — A GitHub Blog/Podcast explainer unpacks terms like "loop engineering," "harnesses," "squads," and "hill climbing" that are showing up more in developer conversations about AI coding tools. (github.blog/ai-and-ml, 2026)
