## Current homepage themes

- GitHub collaboration basics: repositories, branches, pull requests, and merges.
- GitHub Copilot as an AI coding assistant across the IDE, CLI, and GitHub.
- GitHub Actions as the automation layer behind repository workflows.
- Recent GitHub Blog and Changelog stories worth watching.

## Recent updates worth watching (GitHub Changelog, September 2026)

- **Workflow execution protections in GitHub Actions are now generally
  available.** Enterprises, organizations, and repositories can define an
  allowlist controlling who can trigger workflow runs. (github.blog/changelog)
- **Ubuntu 26.04 runner image is generally available** for GitHub Actions on
  both x64 and arm64, out of public preview and ready for production
  workflows. (github.blog/changelog)
- **Repository-level pull requests page refresh is in public preview** for
  all users, adding better filtering and a compact presentation mode.
  (github.blog/changelog)
- **Copilot code review can now approve pull requests.** Copilot flags when a
  PR is ready to approve, and admins can authorize it to sign off; the
  ability is off by default. (github.blog/changelog)
- **Repository rulesets can block pull requests that introduce exposed
  secrets from merging**, giving teams a scalable way to stop secret leaks
  before they land. (github.blog/changelog)
- **Copilot budget increase requests are generally available**, giving
  members a flow to request more AI credits instead of being blocked once
  their allotment runs out. (github.blog/changelog)
