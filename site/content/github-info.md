## Recent GitHub Changelog updates (github.blog/changelog)

- **Copilot code review can now approve pull requests** — Copilot can flag when a PR is ready to approve, and admins can opt in to let it sign off (off by default).
- **GitHub CLI now supports media in issues, PRs, and comments** — a repeatable `--attach` flag on `gh` uploads a local image or video and references it inline.
- **Block pull requests with exposed secrets from merging** — repository rulesets can now stop a PR from merging if it introduces a detected secret.
- **GitHub Actions early September 2026 updates** — includes a new REST API for runner version deprecations, giving clearer visibility into upcoming runner changes.
