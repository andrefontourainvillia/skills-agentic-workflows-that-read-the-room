# GitHub Info

## Mona's editorial angle

Mona's website focuses on practical GitHub guidance backed by official references from:

- docs.github.com
- github.blog
- github.blog/changelog

## Current homepage themes

- GitHub collaboration basics: repositories, branches, pull requests, and merges.
- GitHub Copilot as an AI coding assistant across the IDE, CLI, and GitHub.
- GitHub Actions as the automation layer behind repository workflows.
- Recent GitHub Blog and Changelog stories worth watching.

## Recent stories worth watching

- The refreshed repository Pull Requests page is now generally available, giving
  contributors a clearer view of review status and activity at a glance.
  (Source: github.blog/changelog, Sep 21, 2026)
- Copilot code review has an improved review experience, making it easier to
  scan, act on, and resolve Copilot's suggested changes in a pull request.
  (Source: github.blog/changelog, Sep 18, 2026)
- New GitHub Copilot models continue to roll out weekly, including Claude Opus
  5.5 and Grok 4.7, alongside a heads-up that some older Copilot models are
  being deprecated in mid-October.
  (Source: github.blog/changelog, Sep 22, 2026)
- "Decoding the new AI lingo" breaks down agent terms like loops, harnesses,
  squads, and hill climbing for developers ramping up on AI-assisted workflows.
  (Source: github.blog, Sep 2026)
