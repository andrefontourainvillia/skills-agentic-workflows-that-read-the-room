## Recent GitHub Changelog highlights (September 2026)

- **Copilot code review can now approve pull requests.** Copilot tells you when a pull request is ready to approve, and admins can authorize it to sign off on approvals; the capability is off by default. ([GitHub Changelog](https://github.blog/changelog/2026-09-01-copilot-code-review-can-now-approve-pull-requests/))
- **GitHub CLI can attach media to issues, pull requests, and comments.** A repeatable `--attach` flag on `gh` uploads a local image or video and references it inline in the body. ([GitHub Changelog](https://github.blog/changelog/2026-09-01-github-cli-media-in-issues-pull-requests-and-comments/))
- **Content exclusions are generally available in the Copilot app and CLI.** Copilot now respects content exclusion policies set by enterprise, organization, and repository admins. ([GitHub Changelog](https://github.blog/changelog/2026-09-02-content-exclusions-generally-available-in-copilot-app-and-cli/))
- **Gemini 3.8 Flash is available in GitHub Copilot.** Early testing shows strong performance on complex terminal-based coding tasks. ([GitHub Changelog](https://github.blog/changelog/2026-09-03-gemini-3-8-flash-is-now-available-in-github-copilot/))
- **Selected GitHub Copilot models are being deprecated on October 2, 2026** across Copilot Chat, inline edits, ask/agent modes, and code completions — check the deprecation list before that date. ([GitHub Changelog](https://github.blog/changelog/2026-09-03-upcoming-deprecation-of-selected-github-copilot-models/))
- **GitHub CLI's Linux package signing key expires September 5, 2026.** APT and RPM users should refresh the signing key before installing releases published after that date. ([GitHub Changelog](https://github.blog/changelog/2026-09-03-github-cli-linux-package-signing-key-expires-september-5/))
