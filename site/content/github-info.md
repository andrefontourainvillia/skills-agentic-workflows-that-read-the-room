# GitHub Info

## Mona's editorial angle

Mona's website focuses on practical GitHub guidance backed by official references from:

- docs.github.com
- github.blog
- github.blog/changelog

## Current homepage themes

- GitHub collaboration basics: repositories, branches, pull requests, and merges.
- GitHub Copilot as an AI coding assistant across the IDE, CLI, and GitHub.
- GitHub Actions as the automation layer behind repository workflows.
- Recent GitHub Blog and Changelog stories worth watching.

## Recent highlights (github.blog/changelog)

- **Copilot code review: an improved review experience** — Copilot's PR review
  comments now give a clearer breakdown of findings and recommended changes.
  ([changelog](https://github.blog/changelog/2026-09-18-copilot-code-review-an-improved-review-experience/))
- **Workflow execution protections in GitHub Actions are generally available** —
  repository admins can restrict which workflows are allowed to run, reducing
  the risk of untrusted workflow changes executing in CI.
  ([changelog](https://github.blog/changelog/2026-09-17-workflow-execution-protections-in-github-actions-generally-available/))
- **Ubuntu 26 runner image is generally available** — GitHub-hosted Actions
  runners now offer Ubuntu 26 as the latest supported image for migration.
  ([changelog](https://github.blog/changelog/2026-09-17-ubuntu-26-generally-available-and-latest-migration/))
- **Automated SSO authorization for classic PATs and SSH keys** — organizations
  using SAML SSO can now have classic personal access tokens and SSH keys
  authorized automatically instead of requiring a manual step.
  ([changelog](https://github.blog/changelog/2026-09-16-automate-sso-authorization-for-classic-pats-and-ssh-keys/))
